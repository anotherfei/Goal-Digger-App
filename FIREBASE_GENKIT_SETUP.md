# Goal Digger — Firebase + Genkit (Gemma 4) Setup Guide

## What's in this integration

```
lib/
  firebase/                        ← Flutter-side Firebase layer
    firebase_options.dart          ← Auto-generated by FlutterFire CLI (fill in)
    firebase_initializer.dart      ← One-call init: Core + App Check
    auth/
      auth_service.dart            ← Google Sign-In + anonymous guest + sign-out
      auth_state.dart              ← ChangeNotifier wrapping the auth stream
    firestore/
      firestore_paths.dart         ← All collection/document paths in one place
      firestore_service.dart       ← Generic CRUD + batch + transaction helpers
      repositories/
        goal_repository.dart       ← GoalProject CRUD + real-time stream
        user_repository.dart       ← Profile, streak, coins, pet state
        community_repository.dart  ← Join/leave communities
    sync/
      app_sync_service.dart        ← Bridges Firebase streams → app state
  genkit/
    genkit_config.dart             ← Base URL, model IDs, timeouts
    genkit_client.dart             ← HTTP transport (auth + retry)
    genkit_service.dart            ← DI facade for all flows
    models/ai_models.dart          ← Request/response value objects
    flows/goal_coach_flow.dart     ← goalCoach + taskGenerator + moodAdvisor + focusInsight
  main.dart                        ← Updated entry point (Firebase + Provider)

genkit_backend/                    ← Native Dart Genkit server (Cloud Run)
  lib/
    main.dart                      ← Server entry point + Genkit init
    genkit_server.dart             ← Auth middleware + flow handler + health
    flows/
      goal_coach_flow.dart         ← goalCoach Genkit flow (Gemma 4)
      task_generator_flow.dart     ← taskGenerator + moodAdvisor + focusInsight flows
  pubspec.yaml                     ← genkit + genkit_google_genai packages
  Dockerfile                       ← Multi-stage AOT build for Cloud Run

firebase_config/
  firebase.json                    ← Emulator + hosting config
  firestore.rules                  ← Per-user security rules
  firestore.indexes.json           ← Composite indexes
```

---

## Step 1 — Create Firebase project

1. Go to https://console.firebase.google.com → **Add project**
2. Enable **Firestore** (production mode)
3. Enable **Authentication** → Google provider + Anonymous provider
4. Enable **App Check** (optional but recommended)
5. Note your **Project ID**

---

## Step 2 — FlutterFire CLI (generates firebase_options.dart)

```bash
# Install once
dart pub global activate flutterfire_cli

# In the Flutter app root
flutterfire configure --project=YOUR_PROJECT_ID
```

This replaces `lib/firebase/firebase_options.dart` with real values.

---

## Step 3 — Flutter dependencies

Add to `pubspec.yaml` (or use the provided one):

```bash
flutter pub get
```

Key packages needed:
- `firebase_core`, `firebase_auth`, `cloud_firestore`, `firebase_app_check`
- `google_sign_in`, `provider`
- `genkit`, `genkit_google_genai`
- `http`, `uuid`

## Step 4 — Android setup

In `android/app/build.gradle`:
```groovy
android {
    defaultConfig {
        minSdk 23   // Firebase Auth requires API 23+
    }
}
```

Add `google-services.json` (downloaded from Firebase Console) to `android/app/`.

Add to `android/build.gradle` → `buildscript.dependencies`:
```groovy
classpath 'com.google.gms:google-services:4.4.0'
```

Add to `android/app/build.gradle` bottom:
```groovy
apply plugin: 'com.google.gms.google-services'
```

---

## Step 5 — iOS setup

Add `GoogleService-Info.plist` to `ios/Runner/` (from Firebase Console).

In `ios/Runner/Info.plist`, add your reversed client ID for Google Sign-In:
```xml
<key>CFBundleURLTypes</key>
<array>
  <dict>
    <key>CFBundleURLSchemes</key>
    <array>
      <string>YOUR_REVERSED_CLIENT_ID</string>
    </array>
  </dict>
</array>
```

```bash
cd firebase_config
firebase deploy --only firestore:rules,firestore:indexes \
```

## Step 7 — Get a Google AI Studio key (for Gemma 4)

1. Visit https://aistudio.google.com/app/apikey
2. Create a new key
3. Note the key — you'll use it as `GOOGLE_API_KEY`

> **Alternative (Vertex AI):** If you prefer Vertex AI for Gemma 4,
> change `genkit_google_genai` to `genkit_google_vertexai` in the backend
> pubspec and update the model string to `'google/gemma-4-27b-it'`.

## Step 8 — Run the Genkit backend locally

```bash
cd genkit_backend
dart pub get

# Set env vars
export GOOGLE_API_KEY=your_key_here
export FIREBASE_PROJECT=your_project_id
export PORT=3400

# Run
dart run lib/main.dart
# → 🚀 Goal Digger Genkit backend listening on port 3400
# → Genkit Dev UI: http://localhost:4000
```

Test a flow:
```bash
curl -X POST http://localhost:3400/flow/goalCoach \
  -H "Content-Type: application/json" \
  -d '{"data":{"userMessage":"How do I start?","goalTitle":"Launch portfolio","progressPercent":0.2,"history":[]}}'
```

## Step 9 — Deploy backend to Cloud Run

```bash
cd genkit_backend

# Build + push
docker build -t gcr.io/YOUR_PROJECT/gd-genkit .
docker push gcr.io/YOUR_PROJECT/gd-genkit

# Deploy
gcloud run deploy gd-genkit \
  --image gcr.io/YOUR_PROJECT/gd-genkit \
  --region us-central1 \
  --set-env-vars GOOGLE_API_KEY=your_key,FIREBASE_PROJECT=your_project_id \
  --allow-unauthenticated   # remove this once you verify auth works end-to-end

# Copy the Cloud Run URL → set as GENKIT_BASE_URL in Flutter compile-time define
```

## Step 10 — Connect Flutter to your Cloud Run backend

Run Flutter with:
```bash
flutter run \
  --dart-define=GENKIT_BASE_URL=https://gd-genkit-XXXX-uc.a.run.app \
  --dart-define=GEMMA4_MODEL_ID=gemma-4-it
```

Or add to `launch.json` (VS Code):
```json
{
  "args": [
    "--dart-define=GENKIT_BASE_URL=https://gd-genkit-XXXX-uc.a.run.app"
  ]

```

## Step 11 — Wire AppSyncService into GoalDiggerRoot

In `goal_digger_root.dart`, after `_onboarded = true`:

```dart
// Inside _GoalDiggerRootState
late AppSyncService _sync;

void _completeOnboarding(String provider) {
  final authState = context.read<AuthState>();
  _sync = AppSyncService(uid: authState.uid);

  // Replace seed data with real Firestore streams
  _sync.goalsStream.listen((goals) {
    if (mounted) setState(() => _goals = goals);
  });
  _sync.profileStream.listen((profile) {
    if (profile != null && mounted) {
      setState(() {
        _coins        = profile.coins;
        _streak       = profile.streak;
        _petHappiness = profile.petHappiness;
        _activePetSkin = profile.activePetSkin;
        _selectedMood  = profile.selectedMood;
      });
    }
  });

  setState(() {
    _signedInWith = provider;
    _onboarded    = true;
  });
}
```

## Using Genkit AI in the UI (examples)

### Generate tasks for a new goal
```dart
final genkit = context.read<GenkitService>();

final response = await genkit.taskGenerator.generate(
  TaskGeneratorRequest(
    goalTitle:    'Launch my portfolio',
    category:     'Career',
    deadlineDays: 14,
    priority:     5,
  ),
);

for (final task in response.tasks) {
  print('${task.title} – ${task.durationMinutes} min (${task.load})');
}
```

### Chat with the AI coach
```dart
final response = await genkit.goalCoach.ask(
  GoalCoachRequest(
    userMessage:     'I feel stuck on this goal.',
    goalTitle:       'Exam prep',
    progressPercent: 0.35,
    conversationHistory: _chatHistory,
  ),
);
print(response.reply);
print(response.suggestedActions);
```

### Get a mood-based message
```dart
final advice = await genkit.moodAdvisor.advise(
  MoodAdvisorRequest(
    mood: 'Tired', completedToday: 2, totalToday: 5, streak: 7,
  ),
);
print('${advice.emoji} ${advice.message}');
```

### After a focus session
```dart
final insight = await genkit.focusInsight.analyse(
  FocusInsightRequest(
    taskTitle: 'Draft project outline',
    goalTitle: 'Launch portfolio',
    durationMinutes: 25,
    completed: true,
  ),
);
// Award coins
await _sync.addCoins(insight.coinsEarned);
```

## Environment variable summary

| Variable            | Where set         | Description                         |
|---------------------|-------------------|-------------------------------------|
| `GOOGLE_API_KEY`    | Cloud Run / .env  | Google AI Studio key (Gemma 4)      |
| `FIREBASE_PROJECT`  | Cloud Run / .env  | Firebase project ID                 |
| `PORT`              | Cloud Run         | HTTP port (default 3400)            |
| `GENKIT_BASE_URL`   | `--dart-define`   | Cloud Run URL of the Genkit backend |
| `GEMMA4_MODEL_ID`   | `--dart-define`   | Model string (default `gemma-4-it`) |
